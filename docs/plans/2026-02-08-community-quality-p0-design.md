# 社区质量 P0 设计（执行版）

日期：2026-02-08

## 目标
以“内容质量 + 讨论深度”为优先，先完成 P0：
1) 发帖结构化引导（观点/依据/操作）
2) 评论完整实现 + 引用回复
3) 评论优质排序（点赞/长度/引用/时间）

## 现状要点
- 发帖支持文字/图片/标签，暂无结构化提示
- 评论已支持回复、点赞、撤回，但缺少引用展示
- 排序仅“最新/最热”，缺少“优质”权重

## 方案要点（P0）
### 1) 发帖结构化引导
- 输入框占位提示改为三段式：观点/依据/操作
- 文案提示鼓励结构化表达
- 字数过短（<30字）提示补充依据或操作细节

### 2) 评论引用回复
- 对含 replyToCommentId 的评论，展示“引用内容”块
- 引用内容优先取已加载评论的真实文本，找不到则显示“引用的评论已不可见”
- 评论输入区域展示当前引用摘要，便于二次确认

### 3) 评论优质排序
- UI 将“最热”调整为“优质”
- 客户端排序规则（当 sort=hot）：
  - 先按点赞数降序
  - 再按评论长度降序
  - 再按是否含引用降序
  - 再按时间降序

## 影响范围
- ComposePostView / ComposePostViewModel
- PostDetailView / PostDetailViewModel

## 里程碑
- 完成 UI 与 ViewModel 逻辑（无需改动云函数）
- 验证：发帖提示、引用展示、优质排序切换
